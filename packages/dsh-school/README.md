# 忆鲸鲸 · 上学

让她自己补上那些**你没答、她也没懂**的问题。

聊天里她问出口、又没等到答案的话，会被记成一条「悬着的问」。等你不看她了，她自己挑最久的那条去查；查到了，在你桌上留一张纸条。

只读她的经历，不改 `dsh-fish` 一行代码，也不写她的记忆、不动她的成长。

---

## 它做什么

| 三步 | 具体是什么 |
|---|---|
| **记下来** | 从她的经历里挑出「以问号结尾、且最后一句在问『你』」的话，存成悬着的问；同一句话不同说法会合并成一条，累加被问过几次 |
| **认类别** | 问不清的算「疑惑」，能改写成一句查得到的问题的算「疑问」。**只有疑问会被自动学**，疑惑留着她自己想清楚，或者由你直接答 |
| **自己去学** | 到点、你键鼠安静、在今天的时间窗里、还没学满当天额度时，挑悬得最久的那条疑问，搜网页 / B 站，读得进来的页面才读，提炼成两三句，放进她的档案，并往她桌上放一张纸条 |

## 它不会做什么

- **不写她的记忆。** 学到的答案只进 `~/.dsh/school/studies.json` 和一张纸条，不碰她的 `events.jsonl`。
- **不动她的成长。** 不增加天数、不过阶段门、不记成"她说的话"。
- **不改 `dsh-fish`。** 只读它的 `events.jsonl`，一行代码都不改——这样别人也装得上。
- **不问自家事。** 问的是插件、工具表、`dsh-` 这类网上查不到的东西时，直接跳过并留给你答。

## 装

```bash
dsh plugin --profile web add dsh-school
```

装完不用重启。想立刻确认一眼：

> 让她调 `school_auto`，看开关、节奏、今天学了几条。

## 四个工具

| 工具 | 干什么 |
|---|---|
| `school_scan` | 立刻扫一遍她的经历，把新的悬着的问收进清单 |
| `school_pending` | 看还悬着哪些问，每条带编号，方便你直接答 |
| `school_answer` | 关掉一条（答过了 / 不算问题 / 别再说了） |
| `school_stats` | 清单规模和上次扫描时间 |
| `school_auto` | 看「空闲时自己去学」的开关与最近一次结果，也可以开关 |

## 什么时候它会动手

四个条件同时满足才学一条：

1. 开关开着（`school_auto`）
2. 在时间窗内，默认 `08:00–23:00`
3. **你键鼠安静够久**，默认 10 分钟——它不在你干活的时候抢电脑
4. 今天还没学满 5 条

节奏默认每 30 分钟看一眼。全部可调，写在 `~/.dsh/school/config.json` 的 `learn` 里。

## 数据在哪

| 文件 | 是什么 |
|---|---|
| `~/.dsh/school/questions.json` | 悬着的问清单（与另外两个忆鲸鲸插件共用的提问队列） |
| `~/.dsh/school/studies.json` | 学到的答案，最多 200 条 |
| `~/.dsh/school/state.json` | 每天学了几条、上次学的什么 |
| `~/.dsh/school/learn.log` | 每次 tick 的流水，排查"它好像没动静"时先看这里 |
| `~/.dsh-fish/notes.json` | 她桌上的纸条（和她的空醒、便条共用同一个地方） |

## 运行环境

| 需要什么 | 缺了会怎样 | 谁在提供 |
|---|---|---|
| 大肥鱼人格插件 `@ssamurias/dsh-fish` | 没有经历可读，插件装了也不动 | 你 |
| 本地模型（ollama） | 改问和提炼写不出来，只会搜不会答 | 你 |
| 搜索 API（可选） | 不配就走 360 与 B 站的网页抓取，命中率会低一截 | Tavily 免费额度够用 |

搜索 key 存在 `~/.dsh/school/config.json`，**不进仓库、不进 npm 包**。

## 已知不足

- 焦点是"截取"不是"理解"，个别条目看起来偏干巴。
- 抓网页仍会被反爬挡住（知乎、百科 403）。它宁可说没查到，也不编一个答案给你。
